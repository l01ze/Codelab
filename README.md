# Codelab

Codelab is a browser-based code editor built as a **single HTML file**. It provides a VS Code-inspired development experience with a file explorer, multi-tab editor, integrated terminal, search, command palette, and other developer tools — all from one file.

## Features

* VS Code-inspired interface
* Single-file architecture
* Code editor with syntax highlighting
* File explorer
* Multi-tab editing
* Integrated terminal
* Search and replace
* Command palette
* Keyboard shortcuts
* Project/file management
* Responsive developer workspace
* No build system required

## Getting Started

No installation or dependencies are required.

Simply download or clone the project and open:

```text
index.html
```

in a modern browser.

## Architecture

Codelab is intentionally contained in a single HTML file.

```text
Codelab/
└── index.html
```

HTML, CSS, and JavaScript are all contained within the same file, making Codelab easy to run, share, modify, and deploy.

## Goal

The goal of Codelab is to create a powerful, accessible coding environment that runs directly in the browser while maintaining the familiar workflow and feel of a professional desktop IDE.
